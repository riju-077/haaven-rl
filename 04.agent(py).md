# HavenRL Study Notes: Step 4

## Step 4: `agent.py` (the player / brain)

### 1. What is it?

`agent.py` is the **player** that plays the game from `env.py`.

- **env** = the game: shows the situation, gives a score.
- **agent** = the player: picks a basket every day and **learns** from the scores.

It has 3 parts (3 classes):

| Part | Class | Simple meaning |
|---|---|---|
| The brain | `QNetwork` | Looks at the 34 numbers and gives a score to each basket |
| The memory box | `ReplayMemory` | Stores past days so it can study them later |
| The player | `DQNAgent` | Uses the brain + memory: picks baskets and learns |

**DQN** = **D**eep **Q**-**N**etwork. "Q" just means "score of an action".

### 2. Part 1: The brain (`QNetwork`)

A small neural network. **In: 34 numbers → Out: 3 scores** (one per basket).

```
34 numbers  →  128  →  64  →  3 scores
(what I see)  (thinking layers)  (basket 0, 1, 2)
```

**Example:**
- It sees: Gold rose the last few days, I hold mostly Bond.
- It outputs: `[0.8, 0.3, 0.1]`
- Meaning: "basket 0 looks best (0.8), basket 2 looks worst (0.1)".
- The agent picks the **highest score** → basket 0.

**What does the score mean?** "If I pick this basket today, how much total reward do I expect from today **and** the coming days?"

At the start the brain is random, so its scores are nonsense. Learning fixes them.

Size: about **12,900 numbers (weights)** inside. Tiny, so CPU is enough.

### 3. Part 2: The memory box (`ReplayMemory`)

Every day, the agent saves one memory:

```
(what I saw, what I picked, reward I got, what I saw next, was it the last day?)
```

**Example memory:** `(34 numbers for Monday, basket 0, +0.5, 34 numbers for Tuesday, False)`

- The box holds up to **10,000** memories. When full, the oldest fall out.
- To learn, it grabs **64 random memories** (a "batch"), not days in order.

**Why random?** Days next to each other are very similar (Monday ≈ Tuesday). Learning from them in order is like studying only one chapter again and again. Random days = studying from the whole book.

### 4. Part 3: The player (`DQNAgent`)

Its functions:

| Function | When it's used | What it does |
|---|---|---|
| `act(obs)` | every day | pick a basket (sometimes random, see epsilon) |
| `remember(...)` | every day | put today's memory in the box |
| `learn()` | every day | study 64 random memories and fix the brain a little |
| `update_target()` | every few episodes | refresh the frozen copy (see section 7) |
| `decay_epsilon()` | end of each episode | explore a bit less |
| `save()` / `load()` | after training / in backtest | store the brain in a `.pth` file and read it back |

### 5. Epsilon: explore vs. use what you know

**Epsilon (ε)** = the chance of picking a **random** basket instead of the best one.

**Example (like picking a restaurant):**
- Always going to your favourite = you never find a better one.
- Sometimes trying a new one = you might discover something better.

| When | ε | Behaviour |
|---|---|---|
| Episode 1 | 1.0 | 100% random (knows nothing yet, so it explores) |
| After each episode | × 0.95 | a bit less random |
| Episode ~10 | ≈ 0.60 | 60% random |
| Episode ~59 onwards | 0.05 (minimum) | mostly uses its brain, still 5% random |
| **Backtest** | **0** (`greedy=True`) | never random, we want to see its real skill |

**Old notebook bug fixed:** it lowered ε after **every day** (step), so after ~10 episodes it had stopped exploring. Now it's lowered once per **episode**.

**Old notebook bug fixed:** the backtest used ε = 0.01. Now the backtest uses `greedy=True` → ε = 0.

### 6. How it learns (`learn()`): the key idea

The brain made a **guess**. We compare it with a **better answer** and nudge the brain towards it.

**Better answer (target) = today's reward + γ × best score tomorrow**

**Example:**
- Monday: the brain guessed basket 0 is worth **0.8**.
- It picked basket 0, and the real reward was **+0.5**.
- On Tuesday, the best basket's score is **0.6**.
- γ (gamma) = **0.95**.
- Target = 0.5 + 0.95 × 0.6 = 0.5 + 0.57 = **1.07**
- Guess was 0.8, target is 1.07 → error = 0.27 → nudge the brain so next time it guesses a bit **higher** than 0.8.

Repeat this thousands of times → the scores become sensible.

**Loss** = how wrong the guesses are (average of error²). Going down = learning.

**If it was the last day** (`done = True`): there is no tomorrow, so target = just the reward.

### 7. Gamma (γ): how much the future matters

γ = **0.95** means "tomorrow's score counts 95% as much as today's."

- γ = 0 → only cares about today (short-sighted).
- γ close to 1 → cares about the long run.

**Why it matters for us:** switching baskets costs a fee **today** but may pay off **later**. With γ = 0.95 the agent can see that.

### 8. The frozen copy (`target_net`)

The agent has **two brains**:

| Brain | Job |
|---|---|
| `q_net` | the learning brain: makes guesses, gets updated every day |
| `target_net` | a frozen copy: only used to calculate "best score tomorrow" in the target |

**Why?** If the same brain made the guess **and** the answer, every update would change the answer too. It's like **chasing your own shadow**: you move, the shadow moves.

So the answer comes from a frozen copy, and every few episodes we copy the learning brain into it (`update_target()`).

### 9. One day of training (how train.py will use it)

```
obs = env.reset()                         # start: ₹1,00,000 in cash
every day:
    action = agent.act(obs)               # 1. pick a basket
    next_obs, reward, done = env.step()   # 2. env plays 1 day
    agent.remember(...)                   # 3. save the memory
    agent.learn()                         # 4. study 64 random memories
    obs = next_obs
end of episode:
    agent.decay_epsilon()                 # explore a bit less
    agent.update_target()                 # refresh the frozen copy (every few episodes)
```

### 10. Settings (hyperparameters)

| Setting | Value | Meaning |
|---|---|---|
| `gamma` | 0.95 | how much the future matters |
| `lr` (learning rate) | 0.001 | how big each nudge is (too big = jumpy, too small = slow) |
| `batch_size` | 64 | memories studied per `learn()` |
| `epsilon_start` | 1.0 | fully random at first |
| `epsilon_min` | 0.05 | never below 5% random during training |
| `epsilon_decay` | 0.95 | ε × 0.95 after each episode |
| memory size | 10,000 | max memories in the box |
