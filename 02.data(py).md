## `havenrl/data.py`

**Job:** get clean prices → turn them into daily % changes → split into train/test → scale.

| Function | What it does | Why |
|---|---|---|
| `fetch_prices()` | Downloads real ₹ Close prices for all 3 ETFs | The agent **trades** at these real prices |
| `daily_returns(prices)` | % change each day (0.01 = +1%) | The agent **looks at** these, not at prices |
| `split_train_test(df)` | Train = 2020–2022, Test = 2023–2024 | The agent must be tested on data it never saw |
| `fit_scaler(train_returns)` | Learns each ETF's usual daily move **from train only** | Using test data here = **data leakage** (cheating with the future) |
| `scale_returns(returns, usual_move)` | Divides by the usual move → a normal day ≈ 1 | So Gold, Liquid and Bond can be compared fairly |

### Why % changes instead of prices?
- Old way: the agent saw **prices**. Gold was ₹34 in training but ₹64 in the test, which it had never seen → confused.
- New way: the agent sees **"up 1%" / "down 2%"**. A +1% day looks the same in 2020 and 2024.
- **Looks at** % moves → **trades at** real ₹ prices → profit is real money.

### Why scale (divide by the usual move)?
Each ETF moves a different amount on a normal day (measured on train data):
- Gold: **0.96%** a day
- Bond: **0.26%** a day
- Liquid: **0.05%** a day

Without scaling, Liquid's moves look like nothing next to Gold's. After dividing, a normal day ≈ **1** for all three and a big day ≈ **2–3**.

### Key decisions
- **`raw["Close"]`** → fixes the "Ticker" date bug. yfinance returns 2 header rows (`Price` and `Ticker`); taking `Close` leaves just the ticker names.
- **`[TICKERS]`** → yfinance sorts columns A–Z; this restores our order: Gold, Liquid, Bond.
- **`auto_adjust=True`** → includes dividends in the price. Liquid ETF now rises ₹808 → ₹968 instead of looking flat.
- **`.dropna()`** → keeps only days where **all 3** have a price.
- **Training starts 2020, not 2019** → the Bharat Bond ETF only began trading on **2019-12-30**.
- **`end + 1 day`** → yfinance's `end` date is *exclusive* (it stops the day before), so we add one day to include 2024-12-31.
- **Calculate returns on ALL prices first, then split** → the first test day (2023-01-02) gets its real move (+0.81% for Gold) compared with the last train day. Splitting first would wrongly give it 0.

### Actual output (checked)
- Total: **1237 days**
- Train: **746 days** (2020-01-01 → 2022-12-30)
- Test: **491 days** (2023-01-02 → 2024-12-31)
- After scaling, the test data's typical size ≈ **0.8–1.7** (train = 1). Same ballpark ✅
  (Old min-max way: test went up to **2.3** on a 0–1 scale ❌)
- Liquid has a few big spikes (up to ~8.6), from dividend-adjustment jumps in the price. Rare; fine for now.
